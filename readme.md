## Self-Attention

- **This project is for learning**

### definition

- Self-attention is a machine learning mechanism that lets a model weigh the relevance of different elements within the same input sequence to build context-aware representations.
- The source:([Wekibedia](https://en.wikipedia.org/wiki/Attention_(machine_learning)))
